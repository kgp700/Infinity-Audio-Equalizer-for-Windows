# 개인정보처리방침

**Infinity Audio Equalizer Pro for Windows**  
제작·제공: **KGP Software Lab**  

## 1. 프로그램의 정보 처리
프로그램은 사용자가 선택한 오디오 출력 장치 정보와 EQ 및 음향효과 설정을 사용자의 컴퓨터에서 처리합니다. 장치별 설정과 프리셋은 프로그램 기능을 제공하기 위해 로컬에 저장됩니다.

## 2. 외부 서비스 접속
사용자가 AutoEQ 모델 검색, 관련 파일 다운로드 또는 외부 웹페이지 열기 기능을 이용하면 해당 외부 서버와 통신할 수 있습니다. 이 과정에서 외부 서비스 운영자가 접속 IP 주소 등 통신 정보를 자신의 개인정보처리방침에 따라 처리할 수 있습니다.

## 3. 로컬 설정 파일 및 공유
설정은 사용자의 로컬 데이터 폴더와 연결된 Equalizer APO 설정 폴더 등에 저장될 수 있습니다. 설정을 내보내면 사용자가 선택한 위치에 파일이 만들어집니다. **다른 사람에게 공유** 형식에는 장치 식별자와 개인 경로를 저장하지 않으며, **내 컴퓨터 전체 백업**에는 개인 설정 및 장치 정보가 포함될 수 있으므로 외부 공유에 주의해 주세요.

## 4. 저장 정보 관리
로컬에 저장된 데이터는 사용자가 프로그램의 설정 기능 또는 운영체제의 파일 관리 기능을 통해 관리할 수 있습니다. 파일을 삭제하거나 설정을 초기화하면 해당 설정을 복구하지 못할 수 있습니다.

## 5. 정책 변경 및 문의
정책 내용이 변경될 경우 적용일과 변경 내용을 갱신하여 프로그램 배포 경로를 통해 안내합니다. 개인정보 관련 문의는 프로그램의 공식 배포·지원 채널을 통해 접수할 수 있습니다.
